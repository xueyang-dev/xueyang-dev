## 正在开发

### [Folith · 译页](https://github.com/xueyang-dev/Folith)

**Make every creation global.**

Folith 是面向长文档与专业本地化的**开源、AI 原生桌面翻译工作台**。它将全文上下文、术语、翻译记忆、模型辅助翻译、人工审校和可追溯交付连成一套工作流。

我希望**让 AI 承担重复劳动，同时把重要的语言判断留给人**。

[了解项目](https://github.com/xueyang-dev/Folith) · [下载最新版](https://github.com/xueyang-dev/Folith/releases/latest) · [观看演示](https://github.com/user-attachments/assets/28519895-b8d0-415a-86f9-6a85635901a8)
